# A voice is not a person

A voice clone is a statistical costume. It can sound like a throat you know and still have no right to that throat. Consent is the whole plot. A reference clip is not a vibe file. It is a biometric-ish artifact. Keep it off git. Keep it off screenshots. Keep it out of issue trackers.

If a synthesizer is missing, do not “just use the system voice.” A computer voice is honest when it is labeled as a computer. It becomes a lie when it ships under a human name because the clone failed. Fail closed. Publish nothing. Leave the script on disk for a human to read.

Law around voice cloning is unsettled and local. Some places treat a commercial clone of a living person’s voice as a publicity-rights problem. Some treat non-consensual pornographic clones as a criminal problem. Some have nothing on the books yet and still have fraud statutes. This essay is not legal advice. It is a production rule: do not claim a legal outcome you did not read, and do not put someone else’s family in the script to make the law feel vivid.

Quotes about regulation must come from a source in the corpus or from a fetched article. If you need to say “I am not a lawyer,” say it once. If you need a number — a fine, a year, a count of bills — it must appear in the source text. Rounding a number you saw is allowed. Inventing a number because the sentence wanted rhythm is not.

The host’s identity in this kit is a file you edit: `noncast.toml`. The face on the README is example art a forker should replace. The corpus is how the show thinks. The reference clip is how it sounds. None of those three should be borrowed from a stranger and shipped as yours.
